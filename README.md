# ⚡ EV Novated Lease Calculator — Australia (FY2026–27)

A beautiful, interactive calculator to determine whether novated leasing an electric vehicle in NSW is financially worth it.

🔗 **Live Demo:** https://schoi0209.github.io/EV-Novated-Lease-Calculator/

---

## Features

- **FY2026–27 tax** — ATO resident rates (15% / 30% / 37% / 45%), low income tax offset, 2% Medicare levy with low-income reduction
- **Electric Car Discount (FBT)** — Full exemption for EVs under the $91,661 fuel-efficient LCT threshold (2026–27)
- **Proposed 2027 / 2029 changes** — Lease-start selector models the $75,000 cap and 25% FBT discount (15% statutory fraction) announced in the 2026–27 Budget (not yet law)
- **Post-tax contribution (ECM)** — Where FBT applies, an employee contribution equal to the taxable value is assumed so no FBT is payable
- **GST** — Car GST credit capped at 1/11 of the $69,883 car limit; GST claimed on running costs except rego
- **Reportable fringe benefit** — 20% statutory fraction × 1.8868 gross-up
- **Residual (balloon)** — ATO minimum residuals; lease repayments account for the balloon
- **Side-by-side comparison** — Novated lease vs standard car loan, with verdict
- **2026 EV presets** — BYD Atto 3 Evo, Tesla Model 3 / Model Y / Model Y L, BYD Sealion 7, Kia EV5 / EV6 (list prices, Nov 2026)
- **OVO Energy EV Plan** — Referral link for cheaper home charging
- **Live results panel** — Sticky summary on desktop, floating result bar on mobile
- **Light / Dark mode** — Light by default, manual toggle (remembered once chosen)
- **Classic version** — The previous design is kept at [`classic.html`](https://schoi0209.github.io/EV-Novated-Lease-Calculator/classic.html)
